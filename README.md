## Static Web Server

### Description
Minimal static web server implemented for learning purposes.
Serves static files from a configurable directory without using existing servers such as Nginx or Apache.

### Scope
- Static file serving
- Directory-based project hosting
- Static assets delivery
- Environment-based configuration

### Configuration
- Static files directory is provided via environment variable

### Tech
- Node.js
- JavaScript

### Notes
- Educational project
- Minimal codebase
- Core implementation of a static file server
- Intended as a base for further extension
